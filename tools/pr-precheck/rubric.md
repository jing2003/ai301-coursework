## Verdict rule

Evaluate every check using its stated evidence and pass condition.

- Grade a check `pass` when the available evidence satisfies its pass condition.
- Grade a check `fail` when the evidence demonstrates that its pass condition is not met.
- Grade a check `unclear` when the permitted evidence is insufficient to determine whether the condition is satisfied.

Return `accept` only when every `required` check receives `pass`.

Return `reject` when any `required` check receives `fail` or `unclear`. Treat `unclear` as failing for verdict assembly because unverified readiness cannot be assumed.

`preferred` checks may generate recommendations but never change the final verdict.

Do not reject a PR solely because an outcome is imperfect when the applicable check explicitly permits an honestly disclosed limitation. However, disclosure does not excuse an unrelated change, a misleading claim, or missing evidence necessary to verify the central fix.

Apply this rule consistently without adding new checks or overriding results based on overall impressions.
